# Caiet de cuvinte

Тренажёр румынского языка (A1–A2): слова из учебника, разговорник с карточками, тексты с тестами и правила грамматики с упражнениями.

Открыть: https://sbaiku.github.io/romana/ — на телефоне можно «Добавить на экран „Домой“», и оно откроется как приложение.

## Как устроено

- `index.html` — всё приложение, без сборки и без сервера.
- `data/*.json` — содержимое. Чтобы добавить слова, правила, тексты или фразы, достаточно поправить эти файлы и запушить в `main`: GitHub Pages обновит сайт за минуту-две.
- Прогресс хранится в браузере на устройстве (`localStorage`). Кнопки внизу страницы сохраняют его в файл и загружают обратно — так его можно перенести на другое устройство.

## Форматы данных

`data/words.json` — массив слов:

```json
{ "id": "cafea", "ro": "cafea", "ru": "кофе", "lesson": "Фонетика · стр. 23–24", "n": 66,
  "ex": "Dimineața beau o ___.", "exForm": "cafea", "exRu": "Утром я пью кофе.", "alt": ["…"] }
```

`id` — латиница, цифры и дефис, уникальный (на нём держится прогресс). `ex` содержит `___` на месте слова; `exForm` — форма слова в этом предложении, если отличается от `ro`; `alt` — другие принимаемые ответы.

`data/rules.json` — массив правил: `id`, `n` (порядок), `level`, `title`, `summary`, `task`, `body` (блоки `{h}`, `{p}`, `{note}`, `{list: []}`, `{table: {head, rows}}`, внутри можно `**жирный**`), `exercises` (30 штук: `{q, a, opts?, why?, ru?, alt?, task?}`; без `opts` ответ вписывается). Новые упражнения добавляйте в конец, не меняя порядок старых: прогресс хранится по номеру упражнения.

`data/texts.json` — тексты: `id`, `n`, `level`, `title`, `summary`, `paragraphs` (массив абзацев, абзац — массив `{ro, ru}`), `glossary` (`{ro, ru}`), `questions` (10 штук `{q, a, opts, ru?, why?}`).

`data/phrasebook.json` — темы разговорника: `id`, `n`, `title`, `phrases` (`{ro, ru, note?}`). Новые фразы добавляйте в конец темы.

`data/lex.json` — словарь для подсказок при нажатии на слово: `"форма": {"ru": "перевод", "base": "начальная форма / пояснение"}`. Слова из `words.json` и глоссариев текстов подхватываются автоматически.
